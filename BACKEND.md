# Серверная часть: что нужно для реальной работы

Сейчас приложение хранит всё в памяти телефона. Три функции из списка работают
в приложении полностью, остальные в приложении только подготовлены и ждут сервера.

## Уже работает в приложении (демо)

- Рейтинг скрыт от сотрудников. Его видят руководитель и собственник.
- «Итоги дня»: выполнено, просрочено, не приняли, в работе (вкладка «Команда»).
  Тот же текст формирует `AppState.digestText()`: сервер будет отправлять его.
- Шаблоны повторяющихся задач (в экране «Новая задача»).
- Регистрация: телефон, код из SMS (в демо 1234), имя. Паспорт и БИН спрашиваются позже.
- Приглашение ссылкой: `?invite=КОД&phone=77...`, кнопка «Отправить ссылку в WhatsApp»
  открывает чат WhatsApp с готовым текстом (ссылка wa.me).

## Нужен сервер

| Функция | Что использовать | Заметки |
|---|---|---|
| Настоящий вход по SMS | Firebase Authentication (Phone) или Twilio Verify | в Казахстане проверить доставку и цену SMS |
| Хранение задач, чатов, отчётов, фото | Firebase (Firestore + Storage) или Supabase | правила доступа по компании и роли |
| Push-уведомления | Firebase Cloud Messaging | на вебе нужен service worker и разрешение; на телефоне надёжнее |
| Просрочка, автоматически владельцу | Облачная функция по расписанию раз в 5–10 минут | находит задачи, у которых `due` прошёл, и шлёт push один раз |
| Вечерняя сводка | Облачная функция по расписанию (например, 20:00 по часовому поясу компании) | текст как в `digestText()`, push и WhatsApp |
| Уведомления в WhatsApp | WhatsApp Business Platform (Cloud API) | только заранее одобренные шаблоны сообщений, платные, нужен аккаунт Meta Business |
| Регистрация по ссылке из WhatsApp | уже работает ссылка; нужен сервер, чтобы приглашение хранилось и код проверялся | |

## Что важно знать заранее

- WhatsApp не разрешает свободную рассылку. Первое сообщение человеку отправляется
  только по одобренному шаблону, у Meta своя цена за каждое. Бесплатной рассылки нет.
- На iPhone push в веб-приложении работает, только если добавить его на экран «Домой».
  Для надёжных уведомлений нужно собрать приложение для Android и iOS.
- Пока нет сервера, push, SMS и WhatsApp-рассылку проверить нельзя.
